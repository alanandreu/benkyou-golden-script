# Benkyou: Fine Lexicon

Quiero crear un diccionario japones-catalan y japones-español, y viceversa, online llamando BENKYOU. La paleta de colores es blanca, beige, gris clarito y como color dominante un granate aúlico ostentoso. Con toques dorados. Debe sentirse como algo fino pero elegante, culto y sofisticado. Muestrame varias opciones de diseño de un layout que encaje bien con este tipo de proyectos. También habrán lecciones de gramática, plantillas de kanjis y kana, minijuegos (memoria, seleccion de trazos por orden, etc).
